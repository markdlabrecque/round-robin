# #3: Increase roster and court name readability

## What was built

- Roster checklist names are 18px with brighter contrast.
- Court slots show names at 18px, with the first word above the rest of the name. Multi-word and hyphenated surnames stay together. Single-word names show without an empty second line. Long names wrap, and the court grows instead of clipping.
- Names are rendered with `textContent`, so HTML-like names show as plain text.
- Slots keep their `.player` value storage. Focusing an active slot opens a multiline editor; blur restores the two-line display.
- Locked history slots keep the two-line display when focused and show the gold focus ring immediately.
- `index.html`, `docs/index.html` and `templates/court.html`/`court.css` share the same name rendering and styles. Startup, import, reset and scheduler code are unchanged.

## Tests

- `tests/test_name_presentation.js`: name sizing, two-part display, single-token, long, hyphenated and HTML-like names, editing, storage and history for root, docs and template.
- `tests/test_history_focus.js`: keyboard focus on locked history slots at 1440px and 375px, plus the template.
- Final run in Docker Chromium against the verify harness: scheduler, name presentation and history focus suites, **41/41 passed**.

## Review

Reviewer approved in one round with no must-fix items. It independently ran 31 Chromium and 5 scheduler tests green.

## Verification

Verifier tried the docs demo at 1440, 1280, 768 and 375px: editing, reload, completion, history, reset, shuffle, empty slots, long and HTML-like names, and a keyboard-only pass. Verdict: minor friction. Locked history slots had no visible focus ring. This was fixed and covered by `tests/test_history_focus.js`. Full report: https://github.com/markdlabrecque/round-robin/issues/3#issuecomment-5999337607

Only observed error was the pre-existing `/favicon.ico` 404 (#7).
